Attributions

Project copy, layout, styling, and original interface assets were created for this student project. Historical music metadata should be verified before final submission.

Metadata

  • MusicBrainz was consulted for historical release and credit metadata during project planning.
  • Album and track information in the local JSON files is curated for demonstration and should be checked against authoritative liner notes or metadata before publishing.

Visual assets

  • Logo, hero artwork, favicon, and archive-card cover graphics in this starter build are original SVG assets created for the project.
  • No external album-cover images are used in the starter build.

Project requirements

This project follows the WDD 231 individual website project specification, including three main pages, responsive navigation, dynamic data, Local Storage, an accessible modal, a form action page, and testing requirements.
